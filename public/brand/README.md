# 위드부스 로고

- `withbooth-final-logo.png`: 사용자가 선택한 최종 첨부 이미지 그대로 적용. 1930×815 투명 PNG, 파란 원 안의 흰 W와 원 밖 파란 ithBooth. 웹 공통/인증 헤더에서 사용.
- `app-icon-character.png`: 사용자가 선택한 파란 머리·안경 캐릭터 아이콘 원본. Android 런처의 밀도별 일반/원형/적응형 아이콘과 웹 `/favicon-character.png`, `/apple-touch-icon.png`에 적용한다. 적응형 전경은 흰 배경에 원본을 60% 크기로 배치한다.
- `/favicon.svg`: 기존 Wb 심볼 보존용. 별도 스플래시 이미지는 기존 디자인을 유지한다.

기존 MyBooth 자산은 과거 디자인으로 보존한다. 중간 시안이나 사용하지 않는 폰트는 추가하지 않는다.
